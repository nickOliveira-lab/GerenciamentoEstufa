# 🍽️ Sistema de Controle de Estufa

Sistema desenvolvido em Python para controle de produção, reposição e saída de alimentos em uma estufa organizacional.

---

## 🚀 Funcionalidades

- Cadastro de praças (Proteínas, Guarnições, Bases, Saladas)
- Cadastro de pratos por praça
- Registro de reposição de alimentos
- Registro de saída de alimentos
- Painel de visualização em tempo real
- Relatório final do dia
- Exportação automática para CSV

---

## 🧠 Conceitos aplicados

- Programação Orientada a Objetos (POO)
- Encapsulamento
- Separação de responsabilidades
- Manipulação de arquivos CSV
- Estrutura de dados em classes
